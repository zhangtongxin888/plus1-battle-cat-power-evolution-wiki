Start here / 5-minute route

+1 Battle Cat Power Evolution Beginner Guide

A practical first-five-minutes route: build Evolution Power, train at the scarecrow, earn Wins, then check Level Up and Evolution.

4 minute read · beginner first

The route

Five steps for your first session

The minute labels are a suggested pace, not an in-game timer or a guaranteed result. Keep each phase longer if the current fight still feels unreliable.

01

Opening minute: build Evolution Power

Begin by clicking or tapping. The official description confirms that every click gives Evolution Power, making this the cleanest starting action while you learn the area.

02

Next: train at the scarecrow

Use the scarecrow as your training target before challenging stronger enemies. The developer explicitly identifies the scarecrow as a place to train, but does not publish its exact reward formula.

03

Take a fight you can finish

Move from training into battle and start with an enemy you can defeat reliably. Enemy victories award Wins. Avoid assuming any exact enemy order or stat requirement—the public sources do not document them.

04

Check Level Up and Evolution

After a short batch of wins, review the available Level Up and Evolution options. The systems are confirmed by the developer; the current costs and effects should be read inside the live game.

05

Repeat, then consider Rebirth later

Return to the power–training–battle loop and move up gradually. Rebirth is confirmed, but its exact requirement, multiplier, and retained progress are not publicly documented. Read the in-game confirmation first.

Decision check

When should you move on?

  • If you are repeatedly losing, return to clicking and scarecrow training.
  • If an enemy is reliably manageable, collect a short batch of Wins before reviewing upgrades.
  • If progress slows, compare the current Level Up and Evolution choices shown in-game.
  • If Rebirth is available, read the live reset preview instead of relying on an old guide.
Guide tip

Reliable wins are a guide strategy, not a published game mechanic. The idea is simple: spend less time on failed fights and more time completing the confirmed loop.

Next destination

World 2 is confirmed. Its requirement is not.

Roblox's badge API lists an enabled badge named Reached world 2!That confirms World 2 exists, but it does not reveal the current unlock cost or condition. Follow the live requirement displayed in the game.

Verified note

The title label [W4] is not evidence that World 4 exists. This guide does not turn update labels into unverified world counts.

Before you leave

Your beginner checklist

  • You know clicking gives Evolution Power.
  • You have used the scarecrow as a training target.
  • You have defeated a manageable enemy and earned Wins.
  • You have checked both Level Up and Evolution.
  • You know to read the current Rebirth preview before resetting.
  • You have checked the current codes page before an active session.
