+1 Battle Cat Power Evolution FAQ

Verified answers about Evolution Power, Wins, scarecrow training, Rebirth, World 2, codes, updates, and game identity.

Answers reviewed August 11, 2026

Game basics

Answers without guessed numbers

What does clicking do?

Every click gives Evolution Power, according to the official Roblox game description.

How do I earn Wins?

Defeat enemies. The official description directly identifies Wins as the reward for enemy victories.

What is the scarecrow for?

The developer describes the scarecrow as a training target. Public sources do not confirm its exact reward formula.

Does the game have Level Up and Evolution?

Yes. The developer lists both systems. Current costs, effects, and forms should be checked in the live game.

Does the game have Rebirths?

Yes. Rebirth is listed by the developer, but exact reset rules, requirements, and multipliers are not publicly documented.

Is there a World 2?

Yes. Roblox has an enabled badge named Reached world 2! The exact World 2 unlock requirement still needs to be read in-game.

Does [W4] mean World 4?

No verified source supports that reading. [W4] is treated as an update label; this guide only confirms World 2.

How do I redeem codes?

Open Shop, scroll to the code section at the bottom, enter the code exactly, then press Verify or Redeem. Two independent guide sources agree on this route.

Does the game update every week?

The developer description says everyweek update, but schedules can change. Treat it as the developer's stated plan, not a guarantee.

Is this the official The Battle Cats game?

No affiliation with PONOS could be verified. This Roblox experience is published under the community name +1 Battle cat, and this website is an independent fan guide.
