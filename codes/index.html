Redemption path

How to redeem a code

  1. Open Shop.
  2. Scroll to the code section at the bottom.
  3. Enter the code exactly as listed.
  4. Press Verify or Redeem.

This route is cross-checked by two independent guide sources. Button wording may differ between current versions.

Guide tip

Read the live redemption result before planning around a code. This guide does not assume what any code awards or how long a reward lasts.

Troubleshooting

If a code does not work

  • Remove spaces before or after the code.
  • Match capitalization exactly.
  • Confirm you are in Place ID 111044895242311, not a similarly named game.
  • Try once in a fresh server if the live game was recently updated.
  • Accept that the code may have expired; this site cannot reactivate it.

Return to the core loop even if a code has expired; codes are optional, not the foundation of progression.
